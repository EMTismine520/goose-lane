# B 组暖色卡通 · 38 项可编辑美术

母稿声明为 96×96，全部使用自有 SVG 路径、渐变与描边，无嵌入位图、外部资源或素材授权依赖。香肠、培根、肉丸、鸡蛋、红椒沿用已认可的 B 样板造型与路径；其余 33 项延续相同暖棕轮廓与左上高光。

`catalog.json` 是资产 ID、名称、主体目标尺寸与五张样板原留白范围的制作清单。`masters/` 保存全部 38 项母稿。`draw-new-masters.mjs` 可重新绘制新增 33 项；五张样板直接以 SVG 母稿维护。

从仓库根目录运行：

```powershell
npm ci --registry=https://registry.npmjs.org
npm run art:build
npm run art:check
```

生成工具只调整运行版 viewBox，保留母稿路径，生成公共 SVG、资源清单、共享展示配置及内容哈希。Sharp 0.35.5 已固定在锁文件中。

文件尺寸、棋盘显示框与栅格化纹理各司其职：96×96 是文件声明；34／36／38／42 是棋盘内可见主体最长边；96／192／288 是 DPR 1／2／3 的显式栅格化采样尺寸。允许调整方形 viewBox 校准留白，不改变屏幕主体大小。

A 与旧位图制作资料在本地归档保存，未包含在可复现制作流程和当前运行资源中。
