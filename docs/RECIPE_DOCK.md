# 料理与器具详情栏

5.2.0统一所有手机尺寸的详情栏：上方料理图，下方左侧真实器具图标、右侧主要动作，右侧所需食材保持单行。

- 点击料理图查看介绍、配方及原料来源；点击器具图进入该器具管理，保留菜谱选择、取回投料和任务进度。
- 菜名、器具名和准备说明不常驻显示。完整名称保留在图像说明、可访问名称及详情面板中。
- 订单显示当前厨房库存，器具显示实际投入数量；缺少物品灰显且仍可点。
- 只有材料齐全的实际器具提供开火；制作中、可领取、满盘时分别保留进度、领取、整理。
- 订单中的器具图绑定当前厨房达标的实际设备，优先空闲且可匹配目标配方的实例。无实例时进入设备查看，不能自动购买或远程开火。
- 无烹饪配方的食材单显示对应生产器，进入已有设备管理及来源介绍。
- 成功生产不弹获得提示或首次发现浮层，图鉴、产物反馈和保存行为照常工作；错误仍可见。

底栏继续使用104–144 CSS px，触点至少44×44px。宽度变化只调整图标尺寸和留白，三个食材不会变为上下两行。
