# 游戏资源缓存与自动准备

生产构建在Vite后执行 `scripts/build-sw.mjs`。正式资源的路径、字节数和SHA-256摘要绑定同一发布版本。

## 可玩后立即全量下载

正式入口第一帧可玩后立即注册Service Worker，不等待玩家停手。已有控制worker时直接发送 `PREPARE_GAME`；首次访问在接管后立即准备。核心安装清单中的文件一并请求，全部校验和写入成功才安装成功；失败时等待本轮写入结算，再清理不完整核心。

完整游戏是正式依赖白名单：核心、可达功能代码、必要图标、128/256运行图与已选512原图。诊断、审阅、母稿、导出、美术manifest不自动下载。美术没有固定总量上限；5MiB核心构建检查只约束启动核心，不约束全量准备。

worker读取实际缓存索引后，把所有缺失URL立即交给浏览器。没有应用层并发上限、速度上限、文件间隔、运行图与高清的阶段屏障，也没有输入、拖动、保存、图片忙、省流量、网络类型或隐藏页面的自动暂停。浏览器自行安排连接与传输。

全量下载只缓存字节，不创建全部Image或Phaser纹理。可见图片的消费者队列与解码/纹理回收独立于全量网络请求。

## 请求共享与缓存

同版本同规范URL共享下载、单次正文读取、单次SHA-256校验和缓存提交。`ready`表示已验证、可供前台响应；`committed`表示缓存写入成功。前台不必等待磁盘写入；离线完成量只计入committed。

worker记忆缓存句柄及URL索引，不为每个文件重新枚举所有缓存。跨版本候选只有新摘要匹配才复用。索引扫描合并期间的新写入；恢复可见、显式状态检查和worker重启时核对实际缓存，丢失文件重新补齐。

新下载先读取正文，再对同一份字节校验；内部fetch不同时使用原生integrity和手工摘要重复检查。重建响应保留正确Content-Type，去除已解压正文不适用的压缩编码头，按实际字节设置长度。模块的Origin/Vary差异继续正确处理。缓存不可写时，已验证联网响应仍可使用。

首访接管前的图片按URL快照交接：只有同URL等待原请求结束后复用HTTP缓存，其他资源立即下载。`ART_HANDOFF`携带页面会话及递增序号，覆盖结束、失败和离开；关闭窗口的记录会清除。接管后的前台请求直接加入共享任务。

## 协议与玩家状态

`PREPARE_GAME`携带当前章URL、requestId、接管快照以及可选的主动暂停偏好；它表达自动准备全量资源，不限制到当前章。`GAME_DOWNLOAD_PAUSE`仅用于玩家明确暂停或继续。`GAME_CACHE_STATUS`核对真实缓存；`ART_HANDOFF`更新接管前正在加载的URL。原忙闲暂停及按章排队协议不再用于生产下载。

`GAME_CACHE_STATE`包含release、requestId、当前章就绪、全部章节运行就绪、全量就绪、真实已缓存字节和文件数、接收速度、活动/补试/失败文件数。页面只接受当前控制worker和当前请求的消息。进度独立Context并合并到UI帧，不驱动棋盘根状态更新。接收速度可能包含HTTP缓存读取，不代表公网带宽；100%只表示当前全量清单实际提交完成。

## 失败和恢复

每个失败文件独立处理，健康请求继续。后台失败项按1、3、10秒补试，最多三次自动补试；这只针对失败项，不限制健康请求。摘要不符时绕过HTTP缓存补取该URL。HTTP失败、断网、摘要错误和缓存写入失败分别处理；耗尽后显示重试未完成资源，只补缺失项。

不从调用fetch开始对所有排队文件套30秒总时限。响应正文连续30秒没有新字节才判为接收停滞；整批30秒完全无响应或字节进展时检查未响应的后台请求，不取消前台仍在等待的共享下载。实际Retry-After按服务器响应处理。

下载意图与玩家主动暂停选择保存在版本化资源元数据缓存，不进入游戏存档。worker重启后按真实CacheStorage重建任务，完整文件复用，未提交的半个文件可重下。程序不因隐藏页面主动暂停，但微信或系统可能挂起执行；重新打开立即核对并继续。

缓存真实写入失败才报告存储错误，不设网络类型或预估剩余空间门槛，不删除玩家IndexedDB、Local Storage、手动槽或备份。

## 更新与验收

更新继续由玩家触发：冻结新输入、排空已接受命令、保存成功后激活等待worker并刷新。资源准备不会等待保存busy，更新也不会丢弃已接受命令。本次不新增旧档迁移或历史发布兼容。

测试覆盖全量同时派发、跨档位、同URL共享、首访交接、独立补试、正文停滞与排队超时、用户主动暂停、worker重启、缓存回收、摘要和容量失败、模块Vary、核心安装原子性与完整离线读取。下载实验与桌面浏览器、微信真机结论分别记录。
