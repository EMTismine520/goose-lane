# 游戏资源缓存与自动准备

生产构建在Vite后执行 `scripts/build-sw.mjs`。所有资源以路径、字节数和SHA-256摘要绑定同一发布版本。

## 核心与完整游戏

核心安装清单包含正式入口的静态依赖、棋盘和Phaser及必要图标。动态功能模块后置。安装按文件有界执行，完整核心成功才安装成功，失败只删除当前不完整核心；已安装版本的导航直接返回缓存，不等待网络版本探测。

完整游戏包使用正向角色白名单：正式入口可达功能代码为 `code`；已选图及128/256像素派生为 `art`。512原图的variant为 `large`。审阅、诊断、母稿、导出、构建报告和美术manifest不进入自动下载。完整包不是整个dist目录。当前核心仍有5MiB原始字节上限，已选全部美术不受固定总包体积门槛限制。

## 自动下载协议

页面在可玩后发送 `PREPARE_GAME`，携带当前章资源URL与唯一requestId。URL必须属于本版明确美术清单。worker先准备当前章，再补全部运行图与功能模块，最后补高清原图；相同规范URL只下载一次。

`CACHE_PAUSE`、`CACHE_RESUME`表达前台忙闲与可见性。`GAME_DOWNLOAD_PAUSE`表达玩家的持久暂停选择。`GAME_CACHE_STATUS`读取当前状态。回复 `GAME_CACHE_STATE`包含发布标识、requestId、当前章节就绪、全部章节运行就绪、全资源就绪、真实完成文件/字节和阶段。页面只接受当前控制worker及当前请求的回复。

资源任务合并并保留剩余集合。后台单并发，与前台同URL请求共用worker内的inflight。优先级提升不取消仍被可见消费者需要的请求。首访在控制交接后启动补缓存，HTTP缓存允许复用已下载文件。

## 中断与失败

下载意图存入 `当前版本::downloads` 元数据缓存；资源位于核心缓存及 `当前版本::themes`。重启后按清单和实际缓存重建剩余任务。文件完整保存后才计入完成；中断文件可重下，已完成文件复用。

目标变化只调整下载集合，不修改存档。普通缓存命中不重复计算摘要；跨版本复用需符合新版本摘要。失败网络请求使用有限重试与30秒单次超时，后续等联网或玩家继续；不会无限重试。

容量不足时暂停可选准备并报告缓存不可写，联网资源仍可按需读取。清理仅限本游戏可重下的资源缓存，不删除IndexedDB、手动槽或玩家备份。系统回收缓存后，重新核对并补缺；完成状态不是永久保证。

页面隐藏或关闭不保证持续下载。显示后自动恢复准备；关闭客户端的旧活动记录会移除，避免阻塞仍打开的页面。

## 更新与验收

更新沿用显式激活：先冻结新输入、排空已接受命令、保存成功，再激活等待worker并刷新。发布只保留新版构建文件，不新增历史资源兼容或旧档迁移。现有本地缓存处理沿用，不以清档作为加载失败的解决方式。

验收包含角色白名单、请求共享、前台抢占、玩家暂停持久化、worker终止恢复、非连续章节、摘要不符、配额失败、离线首次打开图鉴与详情，以及核心安装原子性。HTTP和摘要验证、桌面浏览器、真机结果分别记录。
