# B 组暖色卡通交付记录

日期：2026-10-24

本轮将新增的兽肉 10 项、禽肉 7 项、调料 7 项、料理 10 项与设备 4 项，共 38 项统一为 B 风格。所有 SVG 母稿与运行文件均声明 96×96。旧蔬果、人物、界面、街景、物品 ID、配方、数值和存档结构保留。

## 制作与可复现源码

- 母稿：[artwork/b/masters](../artwork/b/masters)，真实可编辑路径、描边与渐变。
- 制作清单：[catalog.json](../artwork/b/catalog.json)；新增 33 项绘制脚本：[draw-new-masters.mjs](../artwork/b/draw-new-masters.mjs)。
- 五张已认可样板保留原路径与已校准 viewBox、展示大小及偏移，仅统一声明与基础加载尺寸。
- `npm run art:build` 生成运行 SVG、清单与共享展示配置；`npm run art:check` 检查尺寸、路径保留、透明边缘、主体占比、覆盖数量和内容哈希。
- Sharp 固定为 0.35.5。SVG 与哈希相关数据使用 LF，避免 Windows 检出换行影响生成结果。
- 38 项运行 SVG 共 **63,898 字节**，低于 256 KiB；可见主体最大尺寸偏差 **0.187** 个棋盘设计像素，低于 0.7 容差。

96×96 是文件声明。棋盘可见最长边为鸡蛋 34、其他食材 36、料理 38、设备 42。显示框由共享配置控制；显式纹理采样在 DPR 1／2／3 下为 96／192／288，布局保持一致。

## 发布与恢复

[正式游戏](https://emtismine520.github.io/goose-lane/)与[独立 B 试玩](https://emtismine520.github.io/goose-lane-art-preview/)从同一源码提交构建，两个站点的 `release.json` 记录该 SHA。独立试玩不注册 service worker。

正式发布仅保留上一版 service-worker 清单中必要的哈希 JS／CSS，以支持已有标签页保存与接受更新；新入口不引用这些旧文件。A 图、双风格目录和替换的 WebP 退出当前公开树，不改写 Git 历史。

[旧恢复链接](https://emtismine520.github.io/goose-lane-art-preview/recover.html)现在自动进入 B 组独立试玩，不再显示修复按钮，也不等待旧存档或注销旧 worker。A 原图、运行图、提示词、来源与尺寸记录已在本地逐文件 SHA-256 核验并保存 ZIP，不进入当前发布流程。

干净检出复现顺序为 `npm ci`、`npm run art:build`、`npm run art:check`、`npm test`、`npm run build`；生成结果应不产生源码差异。部署与干净检出结果另外记录在本轮本地验收目录中。
