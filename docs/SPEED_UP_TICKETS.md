# 加速券规则与界面

适用内容版本5.1.0、存档schema 5。

## 怎么使用

初始拥有100张加速券，已有存档升级时也获得一次100张。所有厨房共享余额，切换或新建章节不再次赠送。100是初始赠送数量，没有自动恢复或每日补充。

1. 投好食材，点击厨具开火。
2. 再点制作中的厨具，打开“立即完成这份料理？”提示。
3. 核对料理、剩余时间和“消耗1张”后的余额，选择确认或取消。
4. 保存成功后，料理立即完成，显示本次消耗和剩余张数。
5. 点击“领取成品”，也可关闭提示后回棋盘领取。

加速只作用于确认的这份任务，包含食材加工、料理和饮品。生成器冷却不使用加速券。厨具详情中的“加速完成”以及保留的旧日加工槽使用同一流程。

没有券时可正常等待。料理已自然完成时不扣券，确认界面自动显示免费领取。满盘仍可加速，成品留在厨具中，整理棋盘后再领取。领取成功才计入已制作数量。

## 界面约定

- 顶栏保持一行：章节 → 体力 → 图鉴 → 金币 → 加速券 → 礼包 → 设置。
- 票券使用奶油色票根、青绿底和双箭头，与体力、金币区分；余额不显示`/100`。点击票券只查看余额和规则。
- 窄屏章节收为图标与序号，资源可上下紧凑显示，按钮保持44px热区。大数缩写只用于顶栏，标题、可访问名称与确认界面显示完整数量。
- 确认卡展示厨具、具体成品、实时剩余时间、消耗、当前和使用后余额，不需要第二次确认。
- 正在保存时禁止再次确认、取消、关闭、Esc及遮罩关闭。失败时在卡内显示原因，允许主动重试。
- 成功使用一次约300ms的票券淡出、进度归满和成品轻亮；业务仅由已提交的存档决定。系统或游戏设置减少动态时直接显示最终状态。
- 触屏、鼠标和键盘激活共用入口；弹层圈定焦点，关闭后归还。低高度下压缩插画并固定操作区，正文仍可滚动阅读。

## 保存约定

余额与厨房任务在同一事务中保存。重复提交、陈旧任务、跨厨房旧确认、只读窗口或写入失败均不会扣券。自然完成与确认同时发生时，由命令执行时的有效时间决定是否已完成；已完成返回0消耗。

schema 0–4验证成功后迁移并初始化一次100张。新版余额为0仍保存为0；缺失、负数、小数和超出保存范围的余额拒绝读取，不以100掩盖损坏。各厨房的物品UID、投料、任务、成品、订单、体力与金币按原记录保留。

手动读档、备份导入和上一快照整体恢复当时的余额与制作进度；旧快照赠送100属于该快照，不叠加到当前余额。重开恢复100，三个手动存档位继续保留。
