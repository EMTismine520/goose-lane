# 交付与验收记录

执行日期：2026-10-23（北京时间）。这是原计划的首个可运行完整内容版本，不能将尚未实施的真人验收标记为已通过。

## 已实现

- 7×8 棋盘，42/49/56 格逐步开放；拖拽和点选、可合成目标提示、独立键盘模式、移出/取消恢复。
- 八条七阶食材链、24 道料理、四台厨具、六章 84 单、六店各三阶段、12 位居民故事、24 件装饰和图鉴搜索。
- 满盘不扣配额、有限仓库、一次出售撤销、原子交单/加工/领取、金币与有上限的装饰加成。
- 手机/桌面适配、原创街景和食品图集、原创 SVG 角色、街边行走/等位/用餐循环、合成回弹、独立音乐音效、减少动态效果。
- 当前/上一份 IndexedDB 快照、严格 schema 校验、v0 迁移、损坏保留、手动备份导入导出、多窗口写锁与冲突保护。
- 生产版本离线缓存、按内容哈希更新、手动激活新版本、静态分发及第三方许可随包保留。

首版生产器采取确定一级产出和固定短冷却，保证恢复路径与清晰成本；随机混合掉落的配置化概率尚未启用。居民动作是与开店数量关联的轻量氛围状态机，不是完整客流经济模拟。24 道料理采用对应食材链的成品图示，因此部分料理共享图像，名称、配方和实例仍独立。

## 发布与回滚

源码与静态构建分开保留。`.openai/hosting.json` 记录唯一 Sites 项目；每次发布先完成检查、同步对应源码提交、打包，然后保存版本并部署。默认站点为所有者私有。

后续回滚应部署已保存的上一版本，保留该版本对应源码、资源与 schema。当前 schema 为 1；不要在不支持高版本存档的旧程序里清档重开。若出现兼容问题，先导出原档，再使用受支持版本恢复。
